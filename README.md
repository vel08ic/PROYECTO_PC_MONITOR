# PC Monitor Local

Herramienta CLI en Python orientada a la administración de sistemas para monitorizar el rendimiento del hardware en tiempo real.

## Características
- **CPU:** Mide el porcentaje de uso total del procesador.
- **Memoria RAM:** Controla el consumo porcentual y los gigabytes libres/totales.
- **Almacenamiento:** Consulta el espacio disponible en el disco principal del S.O.
- **Sensores Térmicos:** Lectura de temperatura de componentes (según compatibilidad del S.O.).
- **Red:** Monitorea el volumen de tráfico acumulado (MB enviados y recibidos).

## Requisitos
- Python 3.x
- Librería `psutil`

## Uso
`python pc_monitor.py`
